# MyWeather Kurdistan

وێبسایتێکی RTL بە کوردی سۆرانی بۆ کەشوهەوا، وزەی خۆر، تۆز و پێشبینی باران.

## چۆن کارپێبکەیت
- `index.html` بکەرەوە لە وێبگەڕێکی نوێدا؛ پێویستی بە build نییە.
- بۆ بەکارهێنانی شوێنی خۆت، لەسەر HTTPS یان localhost کارپێی بکە و ڕێگە بە Location بدە.
- داتاکان لە Open-Meteo وەردەگیرێن و پێویستیان بە API key نییە.

## بەشەکان
- کەشوهەوای ئێستا و پێشبینی ٧ ڕۆژ
- تیشکی خۆر و هەڵسەنگاندنی گونجاوی
- PM2.5، PM10، Dust و European AQI
- بارانی ٢٤ کاتژمێر و ئاگادارییەکی بنەڕەتی

## تێبینی گرنگ
بەشی لافاو تەنیا لەسەر پێشبینی باران هەڵسەنگاندن دەکات؛ پێوانەی ڕاستەوخۆی ئاستی ڕووبار یان ئاگادارکردنەوەی فەرمی نییە. نمرەی وزەی خۆر هەڵسەنگاندنی تیشکە، نەک ژماردنی بەرهەمی پانێڵێکی دیاریکراو.
